VISION PATH

A portable ultrasonic obstacle detection device designed to improve mobility and safety for visually impaired individuals.

Key Features

  • Ultrasonic obstacle detection
  • Dual feedback (buzzer + vibration)
  • LED night assistance
  • Portable handheld design
  • Low-cost and scalable

Technology

  • Arduino Nano
  • HC-SR04 Ultrasonic Sensor
  • Rechargeable battery system
