The Challenge

Visually impaired individuals face significant challenges in navigating both indoor and outdoor environments. Traditional white canes only provide feedback only after physical contact with obstacles, which can lead to accidents and injuries.

Existing smart canes and assistive devices attempt to solve this problem but often suffer from limitations such as:

  • Delayed obstacle detection
  • High cost and lack of affordability
  • Bulky and inconvenient design
  • Dependence on continuous cane usage

Introducing Vision Path

To address these challenges, I developed VISION PATH — a portable, handheld obstacle detection device designed to improve independent mobility for visually impaired individuals.

Unlike traditional solutions, Vision Path is a compact, torch-like device that provides real-time obstacle detection using ultrasonic sensing technology. It is simple, effective, and accessible to users of all age groups.

How It Works

Vision Path uses an ultrasonic sensor to detect obstacles within a safe range of 50 cm to 100 cm.

  • Audio alerts using a buzzer
  • Vibration feedback for tactile response

This dual feedback system ensures reliable alerts in both noisy and silent environments.

Key Features

  • Ultrasonic obstacle detection
  • Dual feedback (buzzer + vibration)
  • LED night assistance
  • Portable handheld design
  • Affordable and scalable
