VISION PATH — Smart Navigation for the Visually Impaired

The Vision

Vision Path is a portable ultrasonic obstacle detection device designed to improve safety and mobility for visually impaired individuals. By using advanced sensors and dual feedback, it provides real-time awareness of the surroundings.

Project Showcase

Key Features

  • Ultrasonic obstacle detection
  • Dual feedback (buzzer + vibration)
  • LED night assistance
  • Portable handheld design
  • Affordable and scalable

Technology

  • Arduino Nano
  • HC-SR04 Sensor
  • Rechargeable battery system
  • TP4056 Charging + Boost Converter
