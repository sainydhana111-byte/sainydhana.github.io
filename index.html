About Me

I am passionate about developing innovative assistive technologies that improve accessibility and independence for visually impaired individuals. My primary project, VISION PATH, focuses on obstacle detection and safe navigation.

Project: VISION PATH

VISION PATH is a portable handheld ultrasonic obstacle detection device designed for visually impaired individuals. It provides real-time obstacle detection using ultrasonic sensing with dual feedback systems:

  • Ultrasonic obstacle detection
  • Buzzer audio alerts
  • Vibration motor tactile alerts
  • LED night assistance system
  • Portable handheld design
  • Rechargeable battery powered

Key Features

  • Detection range: 50 cm – 100 cm
  • Indoor and outdoor optimized modes
  • Suitable for partial and complete blindness users
  • Affordable solution (~₹1500)
  • No smartphone or internet dependency
  • Compact and pocket-friendly design

Future Scope

  • Waterproof enclosure
