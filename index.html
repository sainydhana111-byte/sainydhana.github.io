VISION PATH

A portable ultrasonic obstacle detection device designed to improve safety and mobility for visually impaired individuals using dual feedback systems.

Key Features

  • Ultrasonic obstacle detection
  • Dual feedback (buzzer + vibration)
  • LED night assistance
  • Portable handheld design
  • Affordable and scalable

Technology

  • Arduino Nano
  • HC-SR04 Sensor
  • Rechargeable battery system
